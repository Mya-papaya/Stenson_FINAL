## Assignment Details

For accessibility purposes, I included alt text and an interactive “magnifying glass” feature to enhance the viewing experience when hovering over each piece. The rest of the layout is intentionally straightforward, as I aimed to make the interface as user-friendly as possible.

In the future, I hope to expand this project—using the index page as a landing space for my bio and headshot, and incorporating a navigation bar that links to additional themed galleries.
